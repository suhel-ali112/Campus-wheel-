# 🚲 Campus Wheel

**Campus Wheel** is a web app that helps students travel to and around 
campus at minimal cost. Students can find rides, share journeys,
and save money on daily commutes, with safety and notifications built in.

---

## ✨ Features

- **Sign up & Login**: create an account and sign in securely
- **Find a Ride**: search for available rides to and from campus
- **Ride Details**: view route, timing, cost, and driver/co-passenger info
- **Offer a Ride**: post a ride so other students can join and share costs
- **Notifications**: stay updated on ride requests and confirmations
- **Safety**: safety guidelines and tips for secure travel
- **Profile**: manage your personal details and ride history

## 🚀 Getting Started

### Prerequisites

A modern web browser (Chrome, Firefox, Edge, Safari). No build tools or installation required.

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/suhel-ali112/Campus-wheel-.git
   ```
2. **Open the project folder**
   ```bash
   cd Campus-wheel-
   ```
3. **Launch the app**: open `Index.html` in your browser, or use
4. a local server such as the VS Code *Live Server* extension:
   ```bash
   # Alternatively, with Python
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000/Index.html`.

## 📖 How to Use

1. Open the app and **sign up** for an account.
2. **Log in** with your credentials.
3. Use **Find** to search for a ride, or **Offer** to post one.
4. Open **Ride Details** to review a ride before joining.
5. Check **Notifications** for updates and read the **Safety** page before travelling.
6. Update your information anytime on the **Profile** page.
